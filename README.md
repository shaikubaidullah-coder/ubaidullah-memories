# 🌿 Shaik Ubaidullah — Personal 3D Interactive Memory Scrapbook & Life Vault

A bespoke, tactile, and reflective digital sanctuary created for **Shaik Ubaidullah** — kind, friendly, grounded, and practical. Designed to celebrate life's honest milestones, quiet personal growth, everyday clarity, and cherished memories.

## ✨ Features & Experiences

- **3D Minimalist Desk & Draggable Envelope**: Three.js interactive desk with candle, succulent, mug, books, wax-sealed envelope, and dual confetti celebration.
- **The Essence of Me**: Stacked 3D polaroids with washi tape, daily living log receipt, handwritten sticky notes, and photobooth film strip.
- **Memories Desk & Vintage Studio**: Draggable polaroids, working `lofi-cam` camera that prints snapshots with camera flash, and full 9-photo album vault modal.
- **Retro 90s Mixtape Cassette**: Cassette housing with spinning reels and 3D Side A / Side B tape flipping.
- **4 Official AUR Songs**:
  1. `Raastah` (AUR ft. Taimour Baig)
  2. `Us` (AUR)
  3. `Safarnama` (AUR)
  4. `Tum Se` (AUR)
- **Life Milestones Roadmap**: Hand-drawn interactive roadmap with 5 milestones from Spring 2025 to the present.
- **Handwritten Letter to Myself**: Unfolding 3D envelope with typewriter streaming text and secret dog-eared corner fold.
- **Personal Time Capsule**: Glass cork jar with rising fireflies, reflection prompt saved directly to `localStorage`, and daily principles.
- **3D Wishing Lanterns Night Sky**: Cosmic starry night where you can type intentions or prayers and release glowing 3D paper lanterns into space.
- **3D Living Memory Finale**: Cinematic camera movement lifting hero portrait into 3D space with dream ripples and starlight particles.
- **Custom Vector Favicon**: Warm rose seal with minimalist "U" monogram and golden sprout.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/shaikubaidullah-coder/ubaidullah-memories.git

# Navigate into project directory
cd ubaidullah-memories

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view your memory vault.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation**: Framer Motion, Canvas Confetti
- **Audio Engine**: Web Audio API Procedural Synthesizer + HTML5 Audio Context
- **Styling**: Tailwind CSS
